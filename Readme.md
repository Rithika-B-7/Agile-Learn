⚡ Agile Learn: AI That Adapts To You

Agile Learn is a next-generation personalized education platform that leverages Generative AI to create adaptive, highly interactive learning pathways. By combining Agile methodologies (like Sprints and Kanban) with RPG-style gamification and voice-assisted tutoring, the platform dynamically adjusts to the user's knowledge level, learning speed, and preferred difficulty.

✨ Advanced Features

🧠 Adaptive Curriculum Kanban: Enter a goal, and the AI generates a customized, multi-sprint learning path formatted as a Kanban board (To Do, In Progress, Done). Tasks are saved in real-time.

🎙️ Socratic Voice Tutor: A hands-free, interactive study mode using the Web Speech API. The AI acts as a strict Socratic tutor, asking probing questions rather than just giving direct answers.

💻 AI Code Mentor: A built-in code editor interface where an AI "Senior Engineer" reviews your code for architectural flaws and provides instant feedback.

⚔️ Gamified Quiz Arena: Say goodbye to boring multiple-choice tests. Engage in "boss battles" where you earn XP for correct answers and lose HP for mistakes, complete with health bars and progression tracking.

📈 Dynamic Analytics & Career Mapping: Tracks user progress, predicts mastery timelines, and connects current learning modules to real-world career roadmaps.

🛠️ Tech Stack

Frontend: React.js, Tailwind CSS (Custom Dark UI with liquid-glass effects)

Icons & Typography: Lucide React, Geist Sans, General Sans

Backend / BaaS: Firebase (Firestore & Anonymous Auth)

AI Integration: Google Gemini Pro / Flash API

Browser APIs: Web Speech API (Speech Recognition & Synthesis)

🚀 Getting Started

To get a local copy up and running, follow these simple steps.

Prerequisites

Node.js installed (v16 or higher)

npm or yarn

Installation

Clone the repo:

git clone https://github.com/Rithika-B-7/Agile-Learn.git


Navigate to the project directory:

cd Agile-Learn


Install NPM packages:

npm install


Start the development server:

npm start
# or if using Vite:
npm run dev


(Note: To enable AI generation and Firebase data persistence, you will need to add your own Firebase Config and Gemini API key to the environment variables.)
